# 门店增长智能体

给华为 PC 门店新店员用的销售智能体:输入一句客户线索,一键得到

1. **洞察卡**:五个维度,每条结论带「依据」(客户原话或产品资料)
2. **内容**:朋友圈文案 + 视频切片分镜 + 标题
3. **报价与方案**:四级价格组合(纯代码计算)+ 方案卡 + 3 分钟演示脚本
4. **1/3/7 天跟进**:下一步话术、时机、异议应对

## 快速启动

```
双击 start.bat        # 首次会自动建虚拟环境并安装依赖
浏览器打开 http://127.0.0.1:7860
```

需要 Python 3.10+。没有大模型密钥也能完整运行(用规则模板兜底)。

## 接入大模型(可选)

复制 `.env.example` 为 `.env`,填写 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`(OpenAI 兼容接口)。
`.env` 已在 `.gitignore`,**不要提交密钥**。

## 产品资料(不随仓库发布)

主办方资料不公开,仓库里没有。运行需要把资料包放到 `data_raw/` 下(或设置环境变量 `KB_ROOT` 指向资料包根目录,即包含 `P1-产品参数库` 的那一层)。

## 设计要点

| 要求 | 做法 |
|---|---|
| 价格准确 | `src/store_agent/pricing.py` 纯代码确定性计算;大模型不碰数字。拿不到官方记录时拒绝估价 |
| 全链路不中断 | 每步:大模型(失败重试 1 次)→ 兜底模板;连续失败触发熔断,后续直接走兜底 |
| 不编造 | 内容只用 `facts.py` 从「卖点与限制」抽出的事实包;洞察卡每条带依据 |
| 合规 | `config/banned_words.json` 词表,生成后自动扫描并改写 |

### 四级价格组合(依据资料中的价格字段字典)

| 层级 | 内容 | 规则 |
|---|---|---|
| L1 主机 | 同一 SKU 的官方商城页面价 | 内存/存储/屏幕版本任何一项不同即不同 SKU,信息不全则追问,不猜 |
| L2 条件 | 优惠券、预估到手价 | 只展示,**不自行扣减** |
| L3 配件 | 配件单买价 | 搭配购价只在对应主机页面成立,不计入总价,仅提示 |
| L4 分期 | 主机价 ÷ 12 期 | 与页面「至高12期0分期利息」月供一致,仅主机 |

价格快照里没有金额的型号(下架、仅官网参考起价)一律不报价,提示店内询价。

## 目录

```
app.py                  Gradio 界面入口
start.bat               一键启动
prompts/                提示词(洞察/内容/方案/跟进/系统)
config/                 scenes.json 场景卡;banned_words.json 合规词表
src/store_agent/
  knowledge.py          读取资料包(价格 CSV、产品卖点、场景)
  pricing.py            价格引擎
  facts.py needs.py     事实包 / 需求信号与三档推荐
  fallback.py           兜底模板
  llm.py                大模型调用(重试 + 熔断)
  compliance.py         合规扫描
  pipeline.py           顺序流水线
scripts/run_all.py      全量测试(场景卡 x 产品,含断网/接口报错模拟)
tests/test_pricing.py   20 条价格用例
```

## 测试

```
.venv\Scripts\python -m pytest tests -q          # 价格用例
.venv\Scripts\python scripts/run_all.py          # 全量:60 个组合 + 断网 + 接口 500
```

- 未接入 ima OpenAPI,产品事实读取本地资料副本。
- 无大模型时文案为规则模板,表达较克制。
